# 🤖 Spring AI ChatBot

A production-ready **Spring Boot + Spring AI** chatbot application that integrates with Large Language Models (LLMs) using **Groq/OpenAI-compatible APIs**, supports **Conversation Memory**, **Tool Calling**, and **REST APIs**.

# ⚙️ Configuration

## application.yml

```yaml
spring:
  application:
    name: spring-ai-chatbot

  ai:
    openai:
      api-key: ${OPENAI_API_KEY}
      base-url: https://api.groq.com/openai/v1

      chat:
        options:
          model: llama-3.3-70b-versatile

server:
  port: 9206
```

# 🧠 Conversation Memory

The application uses:

- MessageChatMemoryAdvisor
- InMemoryChatMemoryRepository
- MessageWindowChatMemory

Configured with:

```java
MessageWindowChatMemory.builder()
        .chatMemoryRepository(new InMemoryChatMemoryRepository())
        .maxMessages(10)
        .build();
```

This enables:

- Multi-turn conversation
- Context retention
- Personalized responses

# 🔧 Tool Calling

Example Tool:

```java
@Component
public class SimpleDateTimeTool {

    @Tool(description = "Returns current date and time")
    public String getCurrentDateTime() {
        return LocalDateTime.now().toString();
    }
}
```

The AI automatically invokes the tool whenever the user asks about:

- Current Date
- Current Time
- Today's Date
- Date & Time
